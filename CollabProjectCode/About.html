What is this?

This is the assessment for the module Web Design and Databases (SEN4001). This site is meant to be a system that will be able to book and list local / nearby caravans for the Cardiff and wider Cardiff area. We have strived to make this site useable and to make a system that people will want to use by driving this local company into the modern age with an up-to-date design. We have tried to ensure that the site's design is effective to ensure the experience is the best it can be for all users. We have used many different design principles and concepts to make a site that should be easy to use for many different groups and ages of users.

Who are we?

We are “Design without thinking”. We are a group made up of students all from the design thinking course. We have already done previous web development assessments and projects se we have a strength within this type of work / assessment. This project is the first group project that we have done but we believe that we will work together well and trust that our end product will be of a high standard as we know we can produce sites of that quality.
